# Campus Complaint Management System

A web-based Campus Complaint Management System developed as a Real-Time Project (RTP) to simplify the complaint handling process in educational institutions. The system provides a structured workflow where students can raise complaints, and authorized staff can review, approve, assign, and resolve them efficiently.

---

## 📖 Project Overview

The Campus Complaint Management System enables students to submit complaints related to campus facilities and services. The complaints pass through different levels of approval (HoS, HOD, Admin) before being assigned to the appropriate worker for resolution.

The system ensures transparency, accountability, and role-based access throughout the complaint management process.

## 🔄 Complaint Workflow

```text
Student
   │
   ▼
Head of Section (HoS)
   │
   ▼
Head of Department (HOD)
   │
   ▼
Admin
   │
   ▼
Worker
   │
   ▼
Complaint Resolved
```
